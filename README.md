### 📖 Panoramica

Holding page ufficiale per l'allevamento **Le Garde du Diamond**, dedicato allo **Spitz Tedesco Nano**.  
La pagina è attualmente in fase di sviluppo e offre una **struttura responsive** e una **base SEO ottimizzata**.

---

### 🗂️ Struttura del Progetto

- `/img` — Immagini di base.
- `index.html` — Pagina principale “Coming Soon”.
- `style.css` — Stile personalizzato e responsive.
- `.htaccess` — Ottimizzazione SEO, sicurezza base.
- `robots.txt` — Indicazioni per i motori di ricerca.

---

### 🧰 Tecnologie Utilizzate

- **HTML5** — Struttura semantica della pagina.
- **CSS3** — Layout responsive e design.
- **SEO Base** — Meta tag, robots, struttura ottimizzata.
- **.htaccess** — Sicurezza minima e redirect.

---

### 🛠️ Come Clonare ed Eseguire

```bash
git clone https://github.com/Roberto-Celano/le-garde-du-diamond-holding-page-presentazione.git
cd le-garde-du-diamond-holding-page
```
Apri **index.html** direttamente nel browser per visualizzare la pagina.
